What This Example Shows

The paper studies finite-player dynamic games where each player acts on private information and those actions also change what other players learn. That feedback creates the usual infinite hierarchy of beliefs about beliefs. This explorer shows the paper's two-player benchmark after rewriting the hierarchy as deterministic maps from primitive Brownian shocks to beliefs, actions, and costs.

The main object to watch is the information wedge: the extra term in a player's costate that prices how today's action shifts the opponent's future posterior and therefore the opponent's future action.

The Game

Two players jointly control a scalar state $X_t$ over $[0,T]$. Player 1 wants the state near $b_1$; player 2 wants it near $b_2$. Neither observes the state directly, and each chooses a control using only their own private signal.

State dynamics

The state evolves as

$$dX_t = \bigl(D_t^1 + D_t^2\bigr)\,dt + \sigma\,dW_t^0, \qquad X_0 = x_0,$$

where $W^0$ is common noise observed by neither player, $\sigma$ is the state diffusion coefficient, and $x_0$ is the initial state.

Private signals

Player $i$ continuously observes a private signal

$$dY_t^i = \sqrt{p_i}\,X_t\,dt + dW_t^i, \qquad i=1,2,$$

where $W^1, W^2$ are independent Brownian motions (also independent of $W^0$), and $p_i > 0$ is the signal precision (observation gain $\sqrt{p_i}$). Player 1 sees only $Y^1$; player 2 sees only $Y^2$. Neither player observes the state $X_t$ directly.

Cost functionals

Player $i$ minimizes

$$J^i = \mathbb{E}\!\int_0^T \!\Bigl[\,(X_t - b_i)^2 + r_i\,(D_t^i)^2\,\Bigr]\,dt + q_T\,\mathbb{E}(X_T-b_i)^2,$$

where $b_i$ is player $i$'s bliss point (target state) and $r_i > 0$ is the control cost weight. The paper benchmark sets $q_T=0$; the slider lets you add a terminal target penalty using the same $b_i$ targets.

Equilibrium concept

We look for a Nash equilibrium amongst all admissible strategies. In equilibrium, each player's control decomposes into a deterministic mean path and a feedback response to their innovation process:

$$D_t^i = \bar{D}^i(t) + \int_0^t D^i(t,u)\,d\widehat{W}^i_t(u),$$

where $\bar{D}^i(t)$ is the mean control, $D^i(t,s)$ is the feedback kernel, and $\widehat{W}^i_t$ is player $i$'s noise state. In the plots, $\mathcal{D}^i$ is the same control re-expressed in primitive Brownian coordinates, which is the coordinate system that drives the physical state. The solver finds $\bar{D}^1, \bar{D}^2, D^1, D^2$ such that neither player can reduce their cost by deviating.

Parameters

$p_1, p_2$ Signal precisions — observation gain is $\sqrt{p_i}$
$b_1, b_2$ Bliss points — each player's preferred state level
$r_1, r_2$ Control cost weights — how expensive it is to act
$T$ Time horizon
$q_T$ Terminal tracking weight on $(X_T-b_i)^2$
$N$ Grid points (numerical resolution)

What the plots show

The paper's computational move is to stop tracking beliefs about beliefs directly. Instead, it tracks how the underlying primitive shocks $W^0,W^1,W^2$ flow into beliefs and actions. The plots below are those deterministic maps. They show why private information is costly here not only because players estimate the state imperfectly, but because each player can move the state to influence what the opponent learns.

The noise-state idea

Instead of tracking conditional distributions, work in the coordinates of the three underlying Brownian shocks $W^0, W^1, W^2$. Every adapted process admits a stochastic-integral representation governed by a kernel (a causal function of two time indices), and the equilibrium reduces to a system of coupled kernel equations with no infinite regress. For a first pass, read a kernel value as "the response at time $t$ to a shock that arrived at time $s$." The channels have distinct roles: $W^0$ is common noise observed by neither player, $W^1$ is player 1's observation noise, $W^2$ is player 2's.

State kernel $X(t,s)$

Kernels tab.

$X(t,s)$ is the impulse response of the state: how much a unit shock at source time $s$ persists in $X_t$. The $W^0$ channel starts at 1 and decays as both players stabilize it. The $W^1, W^2$ channels start at zero (observation noise doesn't enter the state directly) but build up as each player's privately-adapted control feeds back through the drift.

Control kernels $D^i(t,s)$ and $\mathcal{D}^i(t,s)$

Kernels tab.

$D^i(t,s)$ is player $i$'s feedback kernel in filtered coordinates (what the player knows). This is the strategy rule. $\mathcal{D}^i(t,s)$ is the same control re-expressed in primitive coordinates (what drives the state), obtained by convolving $D^i$ with the filtration kernel $F^i$. This is the realized impulse response. $\mathcal{D}^i$ is the kernel that enters the state equation and determines equilibrium volatility.

Unresolved state $\widetilde{X}^i(t,s)$

Kernels tab.

$\widetilde{X}^i(t,s)$ is the component of the state's impulse response that player $i$ has not yet resolved at time $t$ — the filtering gain in the noise-state innovation update (Theorem 4.1). The $W^i$ channel is identically zero: player $i$'s own observation noise enters the state only through their own (measurable) actions.

Filtration kernel $F^i(t,u,s)$

Kernels tab.

$F^i(t,u,s)$ maps from primitive coordinates $(s)$ to filtered coordinates $(u)$ for player $i$ at time $t$ — the density kernel of the noise-state conditional mean. The 3×3 subplot grid shows each source channel (column) mapping into each target channel (row).

Mean controls $\bar{D}^i(t)$ and mean state $\bar{X}(t)$

Equilibrium tab (top panel).

The deterministic components of the equilibrium. Dotted lines show the perfect-information Riccati benchmark. The gap is the mean-channel distortion from bilateral belief manipulation. This is the paper's separation failure in the mean channel: changing precision changes the policy rule itself, not only the posterior variance.

Information wedge $\mathcal{V}^i(t,r)$

Mean $\bar{V}^i(t)$ and full kernel $\mathcal{V}^i(t,r)$ on the Equilibrium tab.

Player $i$'s optimality condition gives $D^i(t,s) = -(1/r_i)\,H^i_x(t,s)$, where $H^i_x$ is the kernel costate. In the scalar benchmark, the backward equation for $H^i_x$ is

$$H^i_x(t,r) = H^i_x(T,r) + \int_t^T \bigl[\, X(u,r) + \mathcal{V}^i(u,r) \,\bigr]\,du$$

where $X(u,r)$ is the standard state-tracking term and $\mathcal{V}^i$ is the information wedge. For opponent $k=-i$,

$$\mathcal{V}^{k,i}(t,r) = \sqrt{p_k}\,H^{k,i}(t,t,r)_{\mathrm{obs}} + p_k \int_0^t \widetilde{X}^{k}(t,z)\cdot H^{k,i}(t,z,r)\,dz.$$

The first term prices the newly born current innovation coordinate. The second term prices accumulated drift inference through the opponent's filter. In matrix form this is the Theorem 4.2 / Appendix B expression $\Gamma^k(t)^\top E^k H^{k,i}_t(t,\cdot) + P^k(t)\int_0^t \widetilde{X}^k_t(z)H^{k,i}_t(z,\cdot)\,dz$. Without the wedge, the backward equation collapses to the perfect-information Riccati block. With it, player $i$ shades the drift to manipulate what the opponent learns. This is a finite-player strategic channel; it disappears in exogenous-signal or negligible-agent reductions.

Comparative statics

Statics tab.

Sweeps $p_2$ with all else fixed. Solid lines show pooled-information costs (common filtration, no strategic friction); dashed lines show private-signal equilibrium costs. In the opposing-target benchmark, most of the gain from pooling is strategic: pooling removes the bilateral manipulation channel, not just estimation error.

Precision allocation

Allocation tab.

Sweeps the precision split under the budget $p_1 + p_2 = \bar{P}$. The paper's headline result (Section 2.5): under competition with asymmetric effort costs, a planner should concentrate all precision on the efficient player. The mechanism is information starvation: denying the inefficient player signal access collapses their ability to exert mean control, which in turn reduces the efficient player's incentive to manipulate, collapsing bilateral waste. The certainty-equivalent benchmark (dotted lines in the controls panel) is invariant to the precision split, directly visualizing separation failure (Proposition 4.6): equilibrium policy kernels move with information because the wedge moves with information.

Simulation

Simulation tab.

Generates pathwise realizations of the state, player estimates, and controls using the computed kernels. Each path is constructed as $X_j = \bar{X}_j + \sum_{k \le j}\sum_{\mathrm{ch}} X(j,k,\mathrm{ch})\,\Delta W^{\mathrm{ch}}_k$ where $\Delta W^{\mathrm{ch}}_k = \sqrt{\Delta t}\,Z$ with $Z\sim\mathcal{N}(0,1)$. The $\pm 2\sigma$ bands are computed analytically from kernel norms: $\mathrm{Var}(X_j) = \Delta t \sum_{k \le j}\sum_{\mathrm{ch}} X(j,k,\mathrm{ch})^2$. Player estimates use $\hat{X}^i = X - \tilde{X}^i$ (state minus unresolved component). The filter-error plot shows $X - \hat{X}^i = \tilde{X}^i$, the part of the state invisible to each player. Use the Resample button or change the seed to draw new paths.

Coupled Stationary Kyle-Back PINN

The Kyle-Back block shown here is separate from the two-player LQG game above. It is a scalar stationary price-impact solve with a market maker, two strategic traders, a fundamental shock, public order-flow noise, and two private-signal shocks. The displayed objects all come from the coupled stationary PINN: policy kernels, primitive demand kernels, filter projections, adjoints, and local optimality residuals are fitted together.

The main displayed object is the response to a unit change in the fundamental value: true $V$, market-maker price $P$, and each trader's estimate of $V$. The noise-state tab lets you switch primitive sources $(V,Z,Y^1,Y^2)$ and see how each observer's noise state and each trader's primitive demand kernel respond.

The diagonal birth is an observed innovation coordinate, not a claim that a trader directly sees the primitive noise-trade decomposition. The lag-zero filter diagnostics separately report the observed birth boundary and the unobserved primitive-coordinate boundary.
